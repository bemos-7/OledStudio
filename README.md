# Mini OLED Display Manager

Небольшое desktop-приложение для подготовки изображений под OLED-дисплей
**SSD1306 128×64** и отправки их на **ESP8266** по локальной сети.

Проект появился из довольно простой задачи: хотелось быстро взять
обычную картинку, посмотреть, как она будет выглядеть на маленьком
монохромном OLED, настроить её и отправить результат на ESP8266 без
ручного преобразования изображения через сторонние сервисы.

Приложение делает это в одном окне.

------------------------------------------------------------------------

## Что умеет

-   загрузка обычных изображений;
-   live-preview результата;
-   преобразование изображения в 1-битный формат;
-   настройка порога яркости;
-   инверсия изображения;
-   масштабирование;
-   выравнивание изображения;
-   поворот;
-   отражение по горизонтали и вертикали;
-   предпросмотр в формате OLED 128×64;
-   сохранение последнего изображения;
-   локальный HTTP-сервер на Ktor;
-   передача изображения на ESP8266 по Wi-Fi.

# Как это работает

Схема проекта довольно простая:

``` text
                Компьютер
        ┌───────────────────────┐
        │     OLED Studio       │
        │                       │
        │  Выбор изображения    │
        │          ↓            │
        │  Image2CppConverter   │
        │          ↓            │
        │    128 × 64 bitmap    │
        │          ↓            │
        │     Ktor Server       │
        │       :8006            │
        └───────────┬───────────┘
                    │
                 Wi-Fi/LAN
                    │
        ┌───────────▼───────────┐
        │       ESP8266         │
        │                       │
        │  GET /api/esp/image   │
        │          ↓            │
        │       SSD1306         │
        └───────────────────────┘
```

Компьютер и ESP8266 должны находиться в одной локальной сети.

ESP8266 периодически обращается к компьютеру, получает актуальный массив
изображения и выводит его на OLED.

# Подключение OLED

Для типичной платы NodeMCU ESP8266 используется I²C:

  OLED   ESP8266
  ------ ------------
  VCC    3.3V
  GND    GND
  SDA    D2 / GPIO4
  SCL    D1 / GPIO5

Распиновка может отличаться в зависимости от конкретной платы ESP8266,
поэтому перед подключением лучше проверить pinout своей платы.

В прошивке используется SSD1306:

``` cpp
128 × 64
I2C
address: 0x3C
```

Если у вашего дисплея другой I²C-адрес, его нужно изменить в прошивке.

# Настройка ESP8266

Прошивка находится в проекте отдельно.

Открой её в Arduino IDE и укажи данные своей Wi-Fi сети:

``` cpp
const char* ssid = "YOUR_WIFI";
const char* password = "YOUR_PASSWORD";
```

Далее нужно указать IP компьютера, на котором запущено приложение:

``` cpp
const char* serverName = "http://192.168.1.100:8006";
```

Например, если IP компьютера:

``` text
192.168.1.105
```

то:

``` cpp
const char* serverName = "http://192.168.1.105:8006";
```

**Важно:** здесь не нужно писать:

``` text
/api/esp/image
```

Прошивка сама добавляет этот путь.

Итоговый запрос:

``` text
http://192.168.1.105:8006/api/esp/image
```

Открыть CMD или PowerShell:

``` powershell

```

Например:

``` text
IPv4 Address . . . . . . : 192.168.1.105
```

## macOS

``` bash
ipconfig getifaddr en0
```

Если используется другой сетевой интерфейс:

``` bash
ifconfig
```

## Linux

``` bash
ip addr
```

# Прошивка ESP8266

После настройки Wi-Fi и IP компьютера:

1.  Подключить ESP8266 по USB.
2.  Выбрать нужную плату.
3.  Выбрать COM-порт.
4.  Нажать **Upload**.
5.  Открыть Serial Monitor.
6.  Установить скорость `115200`.

После успешного подключения в Serial Monitor можно увидеть информацию о
подключении к Wi-Fi и запросах к серверу.

# Проверка соединения

Сначала запустите desktop-приложение.

Затем с другого устройства в той же сети откройте:

``` text
http://IP_КОМПЬЮТЕРА:8006/api/esp/image
```

Например:

``` text
http://192.168.1.105:8006/api/esp/image
```

Если всё работает, сервер вернёт JSON примерно такого вида:

``` json
{
    "bytes": [
        0,
        0,
        24,
        60,
        126
    ]
}
```

В реальном ответе будет **1024 значения**, потому что:

``` text
128 × 64 = 8192 пикселей

8192 / 8 = 1024 байта
```

Каждый бит соответствует одному пикселю OLED.

# Работа с изображением

После запуска приложения:

1.  Выберите изображение.
2.  Оно появится в редакторе.
3.  Настройте параметры преобразования.
4.  Смотрите результат в live-preview.
5.  Когда результат вас устраивает, отправьте/сохраните изображение.
6.  ESP8266 получит обновлённый bitmap при следующем запросе.

Основная идея в том, что вы можете менять настройки и сразу видеть
результат, не загружая каждую картинку вручную в `image2cpp`.

------------------------------------------------------------------------

# Преобразование изображения

OLED использует всего два состояния пикселя:

``` text
0 → выключен
1 → включен
```

Поэтому обычная цветная картинка сначала преобразуется в монохромное
изображение.

В приложении для этого используется собственный конвертер в стиле
Image2Cpp.

Итоговый размер всегда:

``` text
128 × 64
```

а результат:

``` text
1024 bytes
```

# Live Preview

Одна из основных частей приложения --- live-preview.

При изменении настроек изображение повторно преобразуется:

``` text
Настройка
   ↓
Image2CppConverter
   ↓
128×64 bitmap
   ↓
Preview
```

Поэтому можно экспериментировать с threshold, инверсией,
масштабированием и другими параметрами, сразу видя результат.

# Передача изображения

Desktop-приложение запускает Ktor HTTP server:

``` text
Port: 8006
```

Основной endpoint:

``` http
GET /api/esp/image
```

Он возвращает текущий bitmap:

``` json
{
    "bytes": [...]
}
```

ESP8266 периодически отправляет этот запрос.

Сейчас интервал между запросами составляет примерно:

``` text
10 секунд
```

Поэтому после изменения изображения на компьютере ESP8266 может обновить
OLED не сразу.

------------------------------------------------------------------------

# Почему используется HTTP

Изначально можно было сделать передачу изображения через USB, но Wi-Fi в
данном случае удобнее.

Получается:

``` text
Компьютер
    │
    │ Wi-Fi
    ▼
  Router
    │
    │ Wi-Fi
    ▼
 ESP8266
    │
    ▼
 OLED
```

ESP8266 не обязан постоянно находиться рядом с компьютером или быть
подключённым к нему USB-кабелем.

------------------------------------------------------------------------

# Если ESP8266 не подключается

Первое, что стоит проверить:

### 1. Запущено ли приложение

Ktor-сервер должен быть запущен вместе с приложением.

### 2. Правильный ли IP

Проверь:

``` cpp
const char* serverName = "http://192.168.1.105:8006";
```

IP должен принадлежать именно компьютеру, где запущено приложение.

### 3. Одна ли сеть

Компьютер и ESP8266 должны иметь доступ друг к другу:

``` text
PC → 192.168.1.105
ESP → 192.168.1.xxx
```

### 4. Firewall

Порт:

``` text
8006
```

должен принимать подключения из локальной сети.

### 5. Guest Wi-Fi

Некоторые роутеры изолируют клиентов гостевой сети.

В таком случае ESP8266 не сможет подключиться к компьютеру.

------------------------------------------------------------------------

# Если OLED показывает мусор

Если вместо картинки появляются случайные точки, полосы или тире, первым
делом стоит проверить:

-   разрешение дисплея --- `128×64`;
-   размер bitmap --- `1024 bytes`;
-   порядок битов;
-   I²C подключение;
-   адрес OLED;
-   соответствие формата bitmap коду `drawBitmap()`.

Проект рассчитан именно на:

``` text
SSD1306
128×64
1 bit per pixel
```

------------------------------------------------------------------------

# Если OLED полностью белый или полностью чёрный

Проверь настройки:

-   Threshold;
-   Invert;
-   цвет фона;
-   цвет изображения.

У монохромного дисплея нет оттенков серого --- после преобразования
каждый пиксель становится либо включённым, либо выключенным.

Если preview в приложении выглядит правильно, а OLED нет, проблема
скорее всего уже на этапе передачи или отображения bitmap.

# Хранение данных

Приложение сохраняет данные в папке пользователя.

### Windows

``` text
%APPDATA%\OledStudio\
```

### macOS

``` text
~/Library/Application Support/OledStudio/
```

### Linux

``` text
~/.config/OledStudio/
```

В частности, используется файл:

``` text
saved_logo.dat
```

Он содержит готовый bitmap для OLED.

Последнее изображение также может сохраняться отдельно, чтобы после
перезапуска приложения его можно было снова открыть в preview и
продолжить работу с настройками.
